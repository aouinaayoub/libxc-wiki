# Libxc Wiki

A static website for browsing Libxc exchange-correlation and kinetic-energy functionals.

Visit the website: [aouinaayoub.github.io/libxc-wiki](https://aouinaayoub.github.io/libxc-wiki/)

The website includes:

- LDA, GGA, meta-GGA, and hybrid functionals
- Search and tag filters
- Functional detail pages
- Equations, publication references, and BibTeX entries

Review-backed excerpts are based on:

Tran, Lehtola, Pittalis, and Marques, *Semi-Local Exchange-Correlation Approximations in Density Functional Theory*, arXiv:2602.17333.
