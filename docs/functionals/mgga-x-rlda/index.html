Different values for the parameter $f$ can be found in the literature683,684,682,685 (see also mgga_x_gp86 discussed below). We note that, with $f=9/10$, the lda_x result is recovered for the HEG. The functional mgga_x_rlda implemented in Libxc corresponds to $f=5/4$, which according to 685 is the value from Campi and Bouyssy683.
