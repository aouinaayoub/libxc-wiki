META-GGA

mgga_c_mn15_l

meta-gga correlation

Review excerpt

This functional has the same analytical form as the correlation component of the M08-HX and M08-SO hybrid functionals,795 with $m=8$ for the sums in eq:m08 . The parameters $c_i$ and $d_i$ were refit together with those in the associated exchange functional, mgga_x_mn15_l. Note that this functional does not reduce to the correct LDA limit of the HEG.

Adapted from Tran, Lehtola, Pittalis, and Marques, Semi-Local Exchange-Correlation Approximations in Density Functional Theory, arXiv:2602.17333.
