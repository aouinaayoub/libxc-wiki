Review excerpt

This is the famous $X_\alpha$ method of Slater50, which he proposed as a simplification of the HF method. In his theory, the exchange functional has the same form as lda_x, but the functional is multiplied by $3\alpha/2$, where $\alpha$ is a parameter. The difference to lda_x is interpreted as correlation:

In Slater's original work, $\alpha=1$, but since then the $X\alpha$ form has been used in numerous applications using values for $\alpha$ fit in a variety of ways (see, e.g., 413 and 414).

Adapted from Tran, Lehtola, Pittalis, and Marques, Semi-Local Exchange-Correlation Approximations in Density Functional Theory, arXiv:2602.17333.
