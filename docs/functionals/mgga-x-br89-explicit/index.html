Review excerpt

In the evaluation of mgga_x_br89, the parameter $c_\sigma$ is obtained by solving a nonlinear implicit equation, eq:mggaxbr89-nonlinear , at each point in space. This can only be done numerically, by using Newton–Raphson method for instance.
