Review excerpt

This is a revised version of gga_x_ssb_d where the parameters in eq:f-kt1 ; eq:fxssbsw were reoptimized. Following the suggestion555,556 to set $s_6=1$ in Grimme's D2 dispersion correction543,544 for a balanced description of dispersion forces, the other parameters were readjusted. The new values are $a=1.082138$, $b=0.177998$, $c=0.246582$, $e=6.284673$, $u=-0.618168$, $f=1.0$, and $r_0=1.3$ (a parameter in the D2 correction that was 1.0 in gga_x_ssb_d). As for gga_x_ssb_d, $d=b(1-u)$ and the constraint $a+b/c=1.804$ was applied.

Adapted from Tran, Lehtola, Pittalis, and Marques, Semi-Local Exchange-Correlation Approximations in Density Functional Theory, arXiv:2602.17333.
