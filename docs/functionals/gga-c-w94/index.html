Review excerpt

Coordinate-scaling relations are often used in functional development, and Wilson610 wondered if their obedience is actually useful for accuracy. To answer this question, he tested various existing and newly proposed functionals that obey coordinate-scaling relations to various degrees. Several new functional forms were constructed using lda_c_wigner as starting point. It turned out that no functional of the considered forms could obey all constraints. We note that $\zeta^{5/3}$ in eq:w94 gives a complex value when $\zeta<0$, which can be overcome by taking the absolute value of $\zeta$, at the price of making it non-differentiable at $\zeta=0$.

The results suggest that adhering to the constraints is beneficial for accuracy.
