Review excerpt

This functional is an alternative version of mgga_c_kcis that is based on the HEG with a gap in the excitation spectrum. The differences with respect to mgga_c_kcis concern eq:kcis-ggaunp ; eq:kcis-ggapol that are now given by

where $t_0=t(\zeta=0)$ (see eq:pw91t ), $e_\text{c}^{\text{PW-LDA}}$ is lda_c_pw, $p=0.193$ (fit to reference atomic correlation energies), and

with $\beta=\beta^{\text{MB}}$. Note that $2^{1/3}r_s$ in eq:kcisk-gamma0 corresponds to $n/2$. Also note that Eq. (22) of Krieger et al.791 is incorrect. The functional was combined with mgga_x_pkzb for the calculation of the atomization energies of molecules.
