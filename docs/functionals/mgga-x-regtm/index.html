Review excerpt

Furness et al.765 noticed that the enhancement factor of mgga_x_tm, eq:fxtm , suffers from the following order-of-limits problem:

that has its roots in the weight function $\tilde{w}_{\sigma}$ ( eq:w-tm ) when $z_{\sigma}$ is calculated from eq:relation2-sigma . To solve this problem, Patra et al.764 proposed to evaluate $\tilde{w}_{\sigma}$ with a modified variable $z_{\sigma}$: \begin {equation} \label{eq:regtm-z-alpha} z_{\sigma}'=\frac{1}{1+\displaystyle \frac{3}{5}\frac{ \displaystyle \alpha_{\sigma}}{\displaystyle p_{\sigma}+f(\alpha_{\sigma})\E^{-cp_{\sigma}}}} \end{equation} where $c=3$ and $f(\alpha_{\sigma})$ is given by eq:f-regTPSS with $d=1.475$. Note that $z_{\sigma}'$ is used only in $\tilde{w}_{\sigma}$, while $F_{\text{x}}^{\text{DME}}$ and $F_{\text{x}}^{\text{SC}}$ use the original variable $z_{\sigma}$. This modification leads to the same value ($\approx 1.1132$) for both eq:regtm-limit1 ; eq:regtm-limit2 .

When used with gga_c_regtpss for correlation, results can be more accurate than those of TM (mgga_x_tm + mgga_c_tm) for some properties, like the phase transition pressure in solids or the band gap. A more recent functional, mgga_c_rregtm, shows better compatibility with mgga_x_regtm.

Adapted from Tran, Lehtola, Pittalis, and Marques, Semi-Local Exchange-Correlation Approximations in Density Functional Theory, arXiv:2602.17333.
