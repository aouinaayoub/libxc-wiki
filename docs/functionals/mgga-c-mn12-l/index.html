META-GGA

mgga_c_mn12_l

meta-gga correlation

Review excerpt

This functional has the same form as the correlation component of the M08-HX and M08-SO hybrid functionals795 with $m=8$ for the sums in eq:m08 . The parameters $c_i$ and $d_i$ were refit together with the associated exchange functional, mgga_x_mn12_l. Note that the correct HEG limit (LDA) was not enforced.

Adapted from Tran, Lehtola, Pittalis, and Marques, Semi-Local Exchange-Correlation Approximations in Density Functional Theory, arXiv:2602.17333.
