Review excerpt

Using reference correlation energies of the He–Ar atoms,629 existing correlation functionals were reoptimized.

gga_c_tm_lyp is a reoptimization of gga_c_lyp. The new values of the parameters in eq:ec-lyp ; eq:lyp-w-omega are $a=0.0393$, $b=0.21$, $\bar c=0.41(4\pi/3)^{1/3}$, and $\bar d=0.15(4\pi/3)^{1/3}$.

gga_c_tm_pbe is a reoptimization of gga_c_pbe. The new values of $\beta$ and $\gamma$ in eq:ggac:pw91h0 ; eq:pw91a are $\gamma=-0.0156$ and $\beta=3.38\gamma=-0.052728$.

gga_c_tm_wpbe is a reparametrization of the correlation part of gga_xc_pbe1w, where the parameter $a_{\text{c}}$ in eq:e-1w was reoptimized to 0.955. Note that lda_c_pw is here used as the LDA component, while it appears that lda_c_vwn was used in the original gga_xc_pbe1w functional.

gga_c_tm_cs1 is a reparametrization of gga_c_cs1, and the new values of the parameters in eq:cs1ab ; eq:cs1aa are $C_1=-0.0398$, $C_2=6.5$, $C_3=-0.0747$, $C_4=-19$, $d=0.514$ and $\gamma=0.00062$.

Compared to their respective original functional, all reoptimized versions improve the correlation energy of the neutral atoms He–Ar and cations Li$^{+}$–K$^{+}$. However, all reoptimized functionals except gga_c_tm_cs1 lead to an increase of the average error for the heavier closed-shell atoms from Ca to Rn.

Adapted from Tran, Lehtola, Pittalis, and Marques, Semi-Local Exchange-Correlation Approximations in Density Functional Theory, arXiv:2602.17333.
