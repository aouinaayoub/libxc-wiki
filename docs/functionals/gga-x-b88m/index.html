Review excerpt

As shown in 512, the original value of the parameter $\beta$ in the enhancement factor of gga_x_b88 ( eq:fxb88 ) might not be optimal for molecular properties. These properties may, of course, depend strongly on the associated correlation functional. Therefore, Proynov et al.511 reoptimized $\beta$ together with the parameters in mgga_c_tau1 using the molecules \ce{N2}, \ce{F2}, \ce{O2}, \ce{HF}, \ce{CN}, \ce{H2O}, \ce{CH4}, \ce{C2H4}, \ce{NH3}, \ce{C6H6}, and the hydrogen-bonded water dimer.513 They obtained the value $\beta=0.0045$.

Adapted from Tran, Lehtola, Pittalis, and Marques, Semi-Local Exchange-Correlation Approximations in Density Functional Theory, arXiv:2602.17333.
