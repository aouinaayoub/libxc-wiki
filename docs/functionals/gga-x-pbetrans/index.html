Review excerpt

This is an attempt from Bremond et al.582 at providing a functional that is more similar to gga_x_pbe_r in the bulk regions (where strong bonds are present) and to gga_x_pbe in the asymptotic regions (relevant to weak interactions), in order to keep the best of both approaches. This is achieved by using the gga_x_pbe form, eq:pbeenh , and interpolating the value of $\kappa$ as follows:

where $\kappa^\text{revPBE}=1.245$ and the interpolating function is chosen to have the form of a Fermi distribution:

In this way, the functional reduces to gga_x_pbe for small values of $s_\sigma$, and to gga_x_pbe_r for large values of $s_\sigma$. Note that this functional is constructed using a similar strategy as for gga_x_bpccac. It was found that large values of $\alpha$ lead to better results but also to issues in the self-consistent field procedure. As in gga_x_bpccac (which uses $x_\sigma$ instead of $s_\sigma$) the value $\alpha=2(3\pi^2)^{1/3}$ is chosen as a good compromise. The chosen value $\beta=3$ represents the upper bound of the physical range of values for $s_\sigma$ in bulk solids.

Combined with gga_c_pbe or gga_c_revtca, the functional is quite accurate for both strongly-bound and weakly-bound systems.

Adapted from Tran, Lehtola, Pittalis, and Marques, Semi-Local Exchange-Correlation Approximations in Density Functional Theory, arXiv:2602.17333.
