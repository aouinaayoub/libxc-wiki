Review excerpt

This is one of the three functionals proposed in 507; the others are gga_xc_hcth_93 and the hybrid B97-1. This functional was used to study the stability of the fit to the analytical form chosen as

The last two terms involve the gga_x_b88 enhancement factor ( eq:fxb88 ) and its derivative with respect to the parameter $\beta$, and they were evaluated at the unmodified value $\beta=0.0042$. The remaining parameters $a_i$ were fit using the same procedure as that for gga_xc_hcth_93, leading to $a_0=1.09878$, $a_1=-2.51173$, and $a_2=0.0156233$. This functional was fit jointly with gga_c_hcth_a, and should therefore be used only in combination with it. Note that since $a_0$ is not equal to one, this functional does not reduce to lda_x for the HEG.

Adapted from Tran, Lehtola, Pittalis, and Marques, Semi-Local Exchange-Correlation Approximations in Density Functional Theory, arXiv:2602.17333.
