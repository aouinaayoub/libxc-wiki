Note that although an unique and positive root exists for $c_\sigma$, there is no closed-form solution, so that eq:mggaxbr89-nonlinear has to be solved numerically (e.g., with the Newton–Raphson method) at each point of space. Once $c_\sigma$ is calculated, $b_\sigma$ can be obtained with $b_{\sigma}=\left[c_{\sigma}^{3}e^{-c_{\sigma}}/ \left(8\pi n_{\sigma}\right)\right]^{1/3}$, which is used for evaluating the energy ( eq:exbr ). Note that the numerical solution of eq:mggaxbr89-nonlinear can be avoided; see the mgga_x_br89_explicit and mgga_x_br89_explicit_1 functionals discussed later, which offer a robust alternative.

Two values for the parameter $\gamma$ in eq:br89-q were considered in 687: $\gamma=1$ (mgga_x_br89_1) and 0.8 (mgga_x_br89), with the later recovering lda_x in the HEG limit.

mgga_x_br89 and mgga_x_br89_1 were combined with the gga_c_p86 correlation functional in 318 and 688, and tested for the geometries and atomization energies of molecules. It turns out that the functional is superior to LDA, and can sometimes compete with BP86 (gga_x_b88 + gga_c_p86). Note that mgga_x_br89 and mgga_x_br89_1 are ($\nabla^2 n, \tau$)-MGGAs.
