By using the above choices, five new variants of gga_x_pbe were proposed: • PBE$(\lambda_\text{CH})$: eq:kappalambda with $\lambda=\lambda_\text{CH}$. • PBE$(\lambda_\text{OC2})$: eq:kappalambda with $\lambda=\lambda_\text{OC2}$. • PBE$(\lambda_\text{LO}(N))$: eq:colambda ; eq:kappalambda with $\lambda_\infty=\lambda_\text{LO}$. • PBE$(\lambda_\text{CH}(N))$: eq:colambda ; eq:kappalambda with $\lambda_\infty=\lambda_\text{CH}$. • PBE$(\lambda_\text{OC2}(N))$: eq:colambda ; eq:kappalambda with $\lambda_\infty=\lambda_\text{OC2}$. Let us recall that the original gga_x_pbe corresponds to eq:kappalambda with $\lambda=\lambda_\text{LO}$. It was found that atomization energies and bond lengths of molecules are rather insensitive to the choice of the LO bound.

The gga_x_lambda_lo_n, gga_x_lambda_ch_n, and gga_x_lambda_oc2_n functionals are implemented in Libxc with $N$ in eq:colambda handled as a user-defined parameter, that is set to $N=\infty$ by default, which leads to gga_x_pbe, gga_x_lambda_ch, and gga_x_lambda_oc2, respectively. The explicit dependence on the number of electrons $N$ makes these functionals formally not semi-local functionals (see discussion for lda_x_rae).
