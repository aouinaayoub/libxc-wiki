Review excerpt

This is another variation of the gga_c_pbe functional, where $\beta$ in eq:ggac:pw91h0 ; eq:pw91a is obtained from $\beta=3\mu^{\text{GE}}/\pi^2\approx0.037526$501 (relation to recover the LDA linear response165) using the value of the density-gradient expansion for exchange $\mu^{\text{GE}}$ in eq:pbeenh .

Adapted from Tran, Lehtola, Pittalis, and Marques, Semi-Local Exchange-Correlation Approximations in Density Functional Theory, arXiv:2602.17333.
